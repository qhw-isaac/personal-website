# 🔄 Tracker Update Commands

Quick reference for updating each tracker. Edit the file listed, then run the command from the project root.

---

## ⏰ Time Tracker (this week + lifetime + landing page)

1. Edit `content/time-tracker/time-tracker-data.csv` (tab-separated: `Activity  ThisWeek  Lifetime`)
2. Run:

```bash
node update-time.js
```

Updates `this-week-data.js`, `lifetime-data.js`, and the hours on `index.html`.

---

## 📚 Book Log (bookshelf)

1. Edit `content/books/reading-log.csv` (comma-separated: `title,author,status,hours,page`)
   - `title` must match the cover filename (without extension), e.g. `Hidden Potential` → `content/books/Hidden Potential.jpg`
   - `status` = `In Progress` | `Pause` | `Idle` | `Complete` (`Complete` shows a "Completed" stamp)
   - leave `page` blank if not started / finished / untracked
   - **Add a book:** drop its cover in `content/books/` and add a row.
   - **Remove a book:** delete its row — it disappears from the shelf.
2. Run:

```bash
node update-book.js
```

Regenerates `content/books/reading-log.js` (the CSV drives both which books show on the shelf and their stats). The cover image is matched automatically by title.

---

## 🎓 MFRE Courses

No CSV — edit the data directly (semester is complete, rarely changes):

`content/time-tracker/mfre-data.js`

---

## 💡 Notes

- Run all commands from the project root.
- After updating, bump the `?v=` number on the changed script in `dashboard.html` (or hard-refresh) so GitHub Pages serves the new file.
